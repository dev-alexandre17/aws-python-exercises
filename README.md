# AWS Python Exercises

Exercícios práticos em Python sobre lógica, funções, manipulação de arquivos e análise de sequências biológicas. Cada pasta contém um exercício independente.

## Exercícios

- `arithmetic-calculator`: calculadora interativa com operações básicas.
- `functions-and-caesar-cipher`: criptografia e descriptografia usando a cifra de César.
- `mixed_types_list`: criação e exibição de uma lista com diferentes tipos de dados.
- `prepoinsulin_sequence_cleanup`: limpeza e análise da sequência de pré-proinsulina.
- `files`: leitura de dados de um arquivo JSON e cálculo aproximado do peso molecular da insulina.

## Requisitos

- Python 3.10 ou superior
- Nenhuma dependência externa

## Como executar

No terminal, entre na pasta do projeto:

```bash
cd aws-python-exercises
```

Execute um exercício, por exemplo:

```bash
python3 arithmetic-calculator/calculator.py
python3 functions-and-caesar-cipher/functions_caesar_cipher.py
python3 mixed_types_list/types_list.py
python3 prepoinsulin_sequence_cleanup/insulin_sequence_variables.py
```

Para executar o cálculo baseado em JSON:

```bash
cd files
python3 calc_weight_json.py
```
